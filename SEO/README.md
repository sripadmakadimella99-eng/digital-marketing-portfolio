# SEO Keyword Research Project

## 🎯 Objective

To identify relevant and high-potential keywords for a digital marketing business and develop a basic SEO keyword strategy.

## 🏢 Business

Digital Marketing Agency

## 🛠️ Tools Used

- Google Keyword Planner
- Google Trends
- Semrush

## 🔍 Project Process

1. Identified the target audience.
2. Created an initial list of relevant keywords.
3. Analysed search intent.
4. Compared keyword opportunities.
5. Grouped keywords based on relevance and intent.
6. Developed SEO recommendations.

## 📊 Key Areas Analysed

- Search volume
- Keyword difficulty
- Search intent
- Competition
- Commercial relevance

## 💡 Recommendations

The selected keywords can be used to plan website pages, blog content and SEO campaigns based on search intent and business relevance.

Keyword research data and analysis will be added to this project.
